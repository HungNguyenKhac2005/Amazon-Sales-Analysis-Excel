## Project Title: Amazon Sales Performance Analysis

Công cụ sử dụng: Microsoft Excel (Power Query, Pivot Table, Advanced Charts).

### 1. Mục tiêu dự án (Objective)

Phân tích dữ liệu bán hàng của Amazon để tìm ra xu hướng doanh thu, các mặt hàng chủ lực và hiệu quả kinh doanh theo khu vực, từ đó đưa ra đề xuất tối ưu hóa lợi nhuận.

### 2. Quy trình thực hiện (Workflow)

Data Cleaning: Xử lý dữ liệu khuyết (Missing values), chuẩn hóa định dạng ngày tháng và loại bỏ dữ liệu trùng lặp bằng Power Query.

Data Analysis: Sử dụng Pivot Tables để trích xuất các chỉ số quan trọng (KPIs) như Tổng doanh thu, Lợi nhuận biên, và Tốc độ tăng trưởng.

Data Visualization: Thiết kế Dashboard tương tác với các Slicer giúp người dùng lọc dữ liệu theo thời gian và danh mục sản phẩm.

### 3. Các Insights quan trọng

(Ví dụ): Doanh thu tập trung 40% vào quý 4 do các chương trình khuyến mãi.

(Ví dụ): Danh mục hàng Điện tử có tỷ lệ hoàn trả cao nhất (15%), cần kiểm tra lại khâu vận chuyển.
